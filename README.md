# Saptaparna Dey | Portfolio

A responsive, dark-themed personal portfolio built with plain **HTML, CSS and JavaScript** (no build step, no dependencies).


## About

I'm a second-year B.Tech CSE (AI & ML) student at Shoolini University. This site showcases my projects, skills, education and contact details.

## Features

- Dark, futuristic design with animated gradient and constellation background
- Typing animation, scroll-reveal effects and hover interactions
- Fully responsive layout with a mobile navigation menu
- Sections: Hero, About, Skills, Projects, Education, Contact
- Respects `prefers-reduced-motion` for accessibility
- Fast: no frameworks or build tools

## Project Structure

```
.
├── index.html      # page structure and content
├── style.css       # styling and responsive layout
├── script.js       # typing effect, animations, menu
└── assets/
    └── profile.jpg # profile photo
```

## Run Locally

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Deployment

Hosted with **GitHub Pages** from the `main` branch (root folder).
